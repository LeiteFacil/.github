# `.github` — Organização Leite Fácil

Repositório público com o perfil da organização e arquivos padrão de comunidade.
Manter este repositório público expõe apenas o conteúdo dele, e **não** torna públicos
os demais repositórios da organização.

> Nada neste repositório deve conter detalhes internos (arquitetura, portas, infraestrutura,
> convenções de equipe, segredos). O conteúdo aqui é visível para qualquer pessoa.

| Caminho | Função |
|---|---|
| `profile/README.md` | README exibido na página da organização |
| `profile/assets/` | Imagens do perfil |
| `SECURITY.md` | Como reportar vulnerabilidades |
| `CODE_OF_CONDUCT.md` | Código de conduta |
| `.github/PULL_REQUEST_TEMPLATE.md` | Template de Pull Request |
| `.github/ISSUE_TEMPLATE/` | Templates de issue |
