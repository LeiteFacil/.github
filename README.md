# `.github` — Arquivos da organização Leite Fácil

Este repositório hospeda os **arquivos compartilhados** (default community health files)
e o **perfil público** da organização. Os arquivos aqui valem para **todos os
repositórios** da org que não tiverem sua própria versão.

> ℹ️ Manter este repositório **público** expõe apenas o conteúdo deste repo
> (perfil + templates). **Não** torna públicos os demais repositórios da organização.

## 📂 Conteúdo

| Caminho | Função |
|---|---|
| `profile/README.md` | README exibido na página da organização |
| `profile/assets/` | Imagens usadas no perfil (logo, banner) |
| `CONTRIBUTING.md` | Guia de contribuição padrão |
| `SECURITY.md` | Política de segurança e reporte de vulnerabilidades |
| `CODE_OF_CONDUCT.md` | Código de conduta |
| `.github/PULL_REQUEST_TEMPLATE.md` | Template de Pull Request |
| `.github/ISSUE_TEMPLATE/` | Templates de issue (bug / feature) |

## 🔧 Antes de publicar

Substitua os *placeholders*:

- `LeiteFacil` → handle da organização no GitHub
- `leite.facil.app@gmail.com` → contato de segurança em `SECURITY.md`
